Therefore it is a very non-trivial problem both to succesfully train and also evaluate the performance of a model on such cases.

\subsection{Taking subset of this dataset}

We already saw that both skyrmions and spirals have vastly different size throughout the phase diagram, and the spirals can also take different shapes. However, instead of dealing with the different shapes and sizes contained within a single phase, we want to focus on improving generalization for mixed configurations in phase transitions. Therefore, we select a subset of the data, where skyrmions and spirals have similar sizes and spirals are arranged in the parallel segments. This subset are highlighted by the black rectanles in the \ref{fig:magnetization_topology}, containing $3710$ samples.

\subsection{Data preprocessing}
Before training any neural network, we need to process the data into a form that both reflects the underlying physics and makes the training procedure more effective. In our case, the raw data are $200 \times 200 \times 3$ vector fields representing spin configurations, and the proper preprocessing is straight forward. From each configuration, we take only the $z$-component, which significantly reduces the data size, while maintaining all relevant information. This choice is also favours practical considerations, because this way we treat the configurations as greyscale images, comparable to experimental images obtained via electron microscopy.

In our case, each pixel value on any image is in the range $[0, 1]$, which is ideal for the model training. When dealing with typical images, the pixel values are integers from $[0, 255]$, in which case using for example min-max scaling for all images is a very important step. It is known to improve convergence by reducing the risk of unnecessarily large or saturated gradients, especially during the early stages of training.

We also split the dataset into training, development, and testing sets. To do this, we utilize physical indicators: the average magnetization and the topological number. These quantities help us to identify regions of the phase diagram where the configurations are single phase ferromagnet, skyrmion, or spiral. In these separated regions, we assign one-hot encoded labels: $(1, 0, 0)$ for ferromagnetic, $(0, 1, 0)$ for skyrmion, and $(0, 0, 1)$ for spiral phase. We dont have a reliable way to label the data from regions near phase boundaries. However, we still store this data in a separate \emph{transitional dataset}, which we can use for further testing. Resulting datasets are visualized in \ref{fig:sub_train_dev_test_split}. The training data contains $450$ samples $175$ ferromagnets, $90$ skyrmions and $185$ spirals.

\section{Perfomance evaluation}
We evaluate the performance of our models in multiple ways. The first metric we monitor is accuracy on the training and validation datasets. The validation accuracy is defined as the proportion of correctly predicted dominant phases. On the other hand, on the test set we accumulate the absolute value of error across the whole set. This way we have more intuitive interpretation of model's performance on the test set. Once we reach a reasonable accuracy on these clean samples, our focus shifts to how well the models handle the cases near phase transitions. Since we have no true labels for such data, we introduce additional custom evaluation metrics, in order to quantitatively compare models on these data. We describe these in the section \ref{metric-definition}.

Finally, we reconstruct the phase diagram using trained models, and visualize their predictions near phase transitions to qualitatively inspect and compare their behavior. 

\subsection{Definition of metrics on phase boundaries}
\label{metric-definition}

We can use the transitional dataset we created \ref{fig:trans_dataset}, and even though we have no labels for the data containing mixtures of phases, we can use our general knowleadge about the phase transitions. 

\begin{figure}[ht]
  \centering
  \begin{subfigure}[b]{\textwidth}
    \centering
    \includegraphics[width=\textwidth]{img/fe_sk_D_07.pdf}
    \caption{Transition from ferromagnet to skyrmion phase, $D = 0.70$}
    \label{fig:trans_fe_sk}
  \end{subfigure}
  \vskip\baselineskip
  \begin{subfigure}[b]{\textwidth}
    \centering
    \includegraphics[width=\textwidth]{img/sk_sp_D_115.pdf}
    \caption{Transition from skyrmion to spiral phase, $D = 1.15$}
    \label{fig:trans_sk_sp}
  \end{subfigure}
  \caption{Examples from the unlabeled \emph{transitional} dataset containing phase transitions}
  \label{fig:trans_dataset}
\end{figure}

The key observation we use is that for a fixed value of $D$, decreasing $B$ should lead to a continuous and monotonic transition from the ferromagnetic skyrmion phase and then from skyrmion to spiral phase. We can group the data in transition dataset by the fixed value of $D$ per transition, gives us a way to evaluate the order of model predictions on transitions. For each $(B, D)$ pair we have $5$ independent configurations. Morever, we can perform data augmentations that represents physically equivalent configurations. So we can also test the consistency of predictions on these equivalent configurations.

To capture these ideas, we define two metrics that we can track throughout the training: \emph{out-of-order} error and \emph{in-group-variance}. 

\begin{enumerate}
\item \textbf{Out-of-order error} measures how well the predicted ordering of phase transitions matches the expected progression. For a fixed $B$, we sort the images by increasing $D$ to define a reference order $r$. We then use the model to predict the dominant phase probabilities and sort the images according to these predictions to get the predicted order $\hat{r}$. We compare $\hat{r}$ and $r$ using the Euclidean norm:
\begin{equation}
	O = \left| \hat{r} - r \right|.
\end{equation}
A lower value of $O$ indicates better alignment with the expected phase transition ordering.

\item \textbf{In-group variance} quantifies the consistency of predictions within groups of the physically equivalent configurations. For each rank $r$, we compute the variance of the predicted probability vectors $p_i$ within the group and sum over all ranks:
\begin{equation}
	V = \sum_r \mathrm{Var}(p_i \mid \hat{r}_i = r).
\end{equation}
\end{enumerate}
A lower value of $V$ means the model consistently predicts similar probabilities for physically equivalent inputs.

\subsection{Feature Map Visualizations}
We can gain insight into a trained convolutional model by visualizing its feature maps. We start with a given input image and pass it through the model. At each convolutional layer, the learned filters are applied to the input, producing a set of feature maps on the output. By visualizing these feature maps, we can get an idea of what kind of features the model is focusing on at different depths. This can help us make more informed decisions when designing or selecting model architectures.

We have also implemented the Grad-CAM method \cite{Selvaraju_2019}, which produces a coarse localization heatmap highlighting the regions in the input that contribute the most to the prediction. The idea is to compute the gradient of the output with respect to the feature maps in the last convolutional layer and use this information to weigh the feature maps. The result is a heatmap that can be overlaid on the input image to indicate important regions.

However, in our case, Grad-CAM did not provide any particularly useful information. This is because the method requires labeled data and works best when specific regions in the image are responsible for the prediction. In our dataset, especially in the clean, single-phase configurations, the relevant features are distributed uniformly across the image, and no single region carries dominant information. As a result, the generated heatmaps were mostly uniform and did not help us interpret the model's behavior in a meaningful way.

\section{Results}

\subsection{Model architectures}

In the paper \cite{iakovlev2018supervised}, the largest lattice authors used was $128 \times 128$. Their best-performing model consisted of a single hidden layer with $64$ neurons and no activation function applied to that layer. They normalized the input by the total magnetization, stating that this step was especially important at the beginning of training, as without it the model would often output only $0$ or $1$. However, this kind of normalization is non-standard and potentially risky for configurations with magnetization close to zero, which can occur in both skyrmion and spiral phases.

The output layer consisted of $3$ neurons with sigmoid activation. This output is not automatically normalized to sum to $1$. Since we want the outputs to represent class probabilities summing to $1$, we manually normalize them, and we will also experiment with a more standard classification activation softmax, which enforces the normalization automatically.

They used mean squared error as the loss function and employed early stopping once a specific accuracy threshold was reached, while also monitoring validation loss to avoid overfitting. The optimizer used was stochastic gradient descent with momentum.

\subsection{Learning rate scheduling}

We evaluated all learning rate scheduling strategies described in \ref{subsec:decay-scheduling}, which are: \emph{None}, \emph{linear}, \emph{exponential}, \emph{cosine}, \emph{piecewise}, and \emph{plateau}. The cosine and plateau schedules consistently led to significantly better models compared to the others. Since the plateau schedule also resulted in faster convergence, we selected it for use in all subsequent experiments.

\subsection{Optimizers}

We have tried multiple optimizing algorithms described in the theoretical part of this thesis: SGD, Adam and RMSprop. Since we have seen that the nature of the task changes with the addition of augmentations, we have tested these optimizers using different augmentations. RMSprop usually does not work well at the beggining of the training, but this is due to relatively larget initial learning rate that we use $\alpha = 0.1$. By the combination with learning rate scheduling, RMS prop ended up outperforming SGD and Adam measured by validation loss and out-of-order metric. Since we use relativelly small training set, we initialy experienced jittering of the training loss. This was however largely eliminated by gradient clipping, where we bounded the $l2$ norm of a gradient by $0.5$.
