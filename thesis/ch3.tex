\subsection{Taking subset of this dataset}

We already saw that both skyrmions and spirals have vastly different size throughout the phase diagram, and the spirals can also take different shapes. However, instead of dealing with the different shapes and sizes contained within a single phase, we want to focus on improving generalization for mixed configurations in phase transitions. Therefore, we select a subset of the data, where skyrmions and spirals have similar sizes and spirals are arranged into parallel segments. The selected subset is highlighted with the black rectanles in the \ref{fig:magnetization_topology}, containing $3710$ samples.

\subsection{Data preprocessing}

Before training any neural network, we want to process the data into a form that both reflects the underlying physics and makes the training procedure more effective. In our case, each data sample is a $200 \times 200 \times 3$ vector field representing  one spin configurations. We start by keeping only the $z$-component, which reduces the data size, while maintaining the relevant information. This choice is also favours practical considerations, because this way we treat the configurations as greyscale images, comparable to experimental images obtained via electron microscopy.

In our case, each pixel value on any image is in the range $[0, 1]$, which is ideal for the model training. When dealing with typical images, the pixel values are integers from $[0, 255]$, in which case using for example min-max scaling for all images is a very important step. It is known to improve convergence by reducing the risk of unnecessarily large or saturated gradients, especially during the early stages of training.

We also split the dataset into training, development, and testing sets. To do this, we utilize physical indicators: the average magnetization and the topological charge. These quantities help us to identify regions of the phase diagram where the configurations are single phase ferromagnet, skyrmion, or spiral. In these separated regions, we assign one-hot encoded labels: $(1, 0, 0)$ for ferromagnetic, $(0, 1, 0)$ for skyrmion, and $(0, 0, 1)$ for spiral phase. We dont have a reliable way to label the data from regions near phase boundaries. However, we still store this data in a separate \emph{transitional dataset}, which we can use for further testing. Resulting datasets are visualized in \ref{fig:sub_train_dev_test_split}. The training data contains $450$ samples $175$ ferromagnets, $90$ skyrmions and $185$ spirals.

We choose a relatively small number of skyrmion samples because these configurations have just minimal deformations in their lattice. Then we picked a two blocks of configurations for each ferromagnet and spiral phase, where in both cases, the blocks are relatively far from the skyrmion phase. This way we train the model on clean single phase configurations, relying on the regularization techniques to generalize to configurations containing some defects or mixtures of two phases. The validation/testing data \ref{fig:sub_dev_test}, were splitted randomly while $20\%$ went to the \emph{validation} dataset which we use during training, and the rest goes to the \emph{testing} dataset.

\subsection{Perfomance evaluation}


We evaluate the performance of our models in multiple ways. The first metric we monitor is accuracy on the training and validation datasets. The validation accuracy is defined as the proportion of correctly predicted dominant phases. On the other hand, on the test set we accumulate the absolute value of error across the whole set. We have in total $2608$ testing samples, therefore the worst test performance model can have is $2608$. However, having a total test error of $0$ isn't neccesarily the best either. Once we reach a reasonable accuracy on these clean samples, our focus shifts to how well the models handle the cases near phase transitions. Since we have no true labels for such data, we introduce additional custom evaluation metrics, in order to quantitatively compare models on these data. We describe these in the section \ref{metric-definition}. Finally, we reconstruct the phase diagram using trained model, and visualize their predictions near phase transitions to qualitatively inspect and compare their behavior. 

\paragraph{Performance metric on phase boundaries}

To define a sensible metric to evaluate predictions on mixed phase configuration, we use the transitional dataset \ref{fig:trans_dataset}, together with our general knowleadge about the phase transitions.

  \label{fig:trans_dataset}

The idea is that for a fixed value of $D$, decreasing $B$ leads to a continuous and monotonic transition from the ferromagnetic skyrmion phase, resp. from skyrmion to spiral phase. We can group the data in transition dataset by the value of $D$ for each of the two transitions, giving us a way to evaluate at least the order of model predictions on transitions. This allows us to define the \emph{out-of-order error}, where based on the natural ordering, we assign each configuration with a rank $r \in {1, \cdots, n}$, where $n$ is a number of configurations in a given group. Then we use a model to make predictions on the same samples, and assing each the predicted order $\hat{r}$. We compare $\hat{r}$ and $r$ using the Euclidean norm:
\begin{equation}
	O = \left| \hat{r} - r \right|.
\end{equation}
A lower value of $O$ indicates better performance on the transition.

\subsection{Feature Map Visualizations}
We can gain insight into a trained convolutional model by visualizing its feature maps. We start with a given input image and pass it through the model. At each convolutional layer, the learned filters are applied to the input, producing a set of feature maps on the output. By visualizing these feature maps, we can get an idea of what the model sees at the different depths. This can help us make more informed decisions about the architectures.

\section{Results and discussion}

All our experiments were conducted under the proper initialization method, as described in \ref{sec:init}. Nevertheless, the progression and the result of a training still depends on the initial model weights, which are essentialy random. Therefore our stratedy is to train multiple models (at least $5$) for each setting with a different random seed. Then we pick ones for which the training succesfully converged based on the training and validation loss, and use those compare different settings.

\subsection{Model architectures}

We begin by implementing the dense neural network, used in \cite{iakovlev2018supervised} on the same problem. Their best-performing model consisted of a single hidden layer with $64$ neurons and no activation function applied to that layer. The output layer consisted of $3$ neurons with sigmoid activation. This output is not automatically normalized to sum to $1$. Since we want the outputs to represent class probabilities summing to $1$, we manually normalize them, and we will also experiment with a more standard classification activation softmax, which enforces the normalization automatically.

They used mean squared error as the loss function and employed early stopping once a specific accuracy threshold was reached, while also monitoring validation loss to avoid overfitting. The optimizer used was stochastic gradient descent with momentum.

The total number of parameters for this network is $2,560,259$. The results of this network are well described by its reconstruction of the phase diagram in \ref{fig:ffn_mazurenko}. We clearly see that the model overfits the training data and fails to generalize, as it tends to interpret unseen skyrmion lattices as magnetic spirals. To address this, we can try applying regularization techniques and observe whether they improve generalization. The resulting phase diagram is shown in \ref{fig:ffn_regularized}.

The regularization methods used were L2 regularization with a value of $0.01$, focal loss, label smoothing of $0.05$, and dropout with a rate of $0.5$. This heavy regularization ended up improving the results the most. However, the overall performance very remains poor. Comparing with the \cite{iakovlev2018supervised}, we the 2 important differences. Firstly they were using configurations with resolutions $48 \times 48$ up to $128 \times 128$, which results in significanlt smaller input layer then we have with $200 \times 200$ lattices. The second and very important reason is that we use much smaller training dataset: $450$ against $~4000$.


Next we move on to the convolutional neural networks. To find a correct number of parameters for each convolutional architecture that we implement, we performed a grid search of different depths and number of filters. When it comes to some basic hyperparameters, we ReLU activations with softmax classification head, max pooling as a pooling layer, standard convolution, and always used batch normalization. Both dropout and spatial dropout were inactive, using only the original data without augmentations. Default optimizer SGD with momentum.

However, even in such cases, the GAP would often outperform flattening on our metrics defined on the configurations near phase transitions, see \ref{fig:flatten-gap}. A possible explanation is that the model using GAP effectively summarizes the overall activation of features corresponding to a particular phase. This helps it generalize to configurations near phase transitions, where mixed or partial patterns occur. GAP might be more sensitive to the relative strength of activations for different phases, and therefore better at recognizing cases where one phase gradually transitions into another.

\subsection{Learning rate scheduling}

We evaluated all learning rate scheduling strategies described in \ref{subsec:decay-scheduling}, which are: \emph{None}, \emph{linear}, \emph{exponential}, \emph{cosine}, \emph{piecewise}, and \emph{plateau}. The cosine and plateau schedules consistently led to significantly better models compared to the others. Since the plateau schedule also resulted in faster convergence, we selected it for use in all subsequent experiments.

\subsection{Optimizers}

We have tried multiple optimizing algorithms described in the theoretical part of this thesis: SGD, Adam and RMSprop. Since we have seen that the nature of the task changes with the addition of augmentations, we have tested these optimizers using different augmentations. RMSprop usually does not work well at the beggining of the training, but this is due to relatively larget initial learning rate that we use $\alpha = 0.1$. By the combination with learning rate scheduling, RMS prop ended up outperforming SGD and Adam measured by validation loss and out-of-order metric. Since we use relativelly small training set, we initialy experienced jittering of the training loss. This was however largely eliminated by gradient clipping, where we bounded the norm of a gradient by $0.5$.

\paragraph{Activation}

We have tested multiple activation functions on the hidden layers, described in the \ref{sec:activation}.

The best performances (test error) for each activation function were: GELU (3.11), Leaky ReLU (7.86), ReLU (8.34), ELU (11.88), tanh (33.60), SELU (34.75), and linear (46.56).
 
Experimentally, the GELU activation function achieved the best test performance, without a loss of performance on the phase transitions. Therefore we use GELU activations in all further experiments.

\subsection{Classification head}


The performance of the models using the two classification heads are very similar considering multiple outcome metrics. The softmax models achieve slightly lower loss and lower testing error \ref{tab:head_comparison}. However, even while having larger validation loss and higher test error, the sigmoid head have consistently better out-of-order metric on the phase transition between skyrmion and magnetic spiral phase \ref{fig:head-sk-sp}. Even though the softmax is the most common activation function on the output layer for classification, the exponential in the softmax suppresses all but the most significant class quite drastically. This is preferable for the case where each sample belongs to the single class. We would like to be able to indentify how much of each phase is present in the given configuration, softmax might not be the best choice.

\subsection{L2 regularization}

L2 regularization only worsened the results. This can be explained by the fact that the CNN models are not overfitting in the first place. Therefore the additional constraining of model's parameters prevented the learning of the basic features and led to underfitting.

\subsection{Label smoothing}

The situation with label smoothing is similar to L2 regularization. Unlike in the dense network, CNNs doesn't need additional help to learn the single phase configurations. While the models trained with label smoothing predict somewhat smoother probabilities as they don't give probability of one even to the single phase configurations, it does not improve the model's performance on the phase transitions

\subsection{Data Augmentations}

We apply the data augmentations directly on batches during the traning $90\%$ of the time. Meaning the the proportion of augmenten vs. non-augmented samples in our training is approximatelly $9:1$.

We first applied the data augmentations that creates physically equivalent configurations. These are reflextions, rotations, rolls and ferromagnet flips as described in \ref{items:physical-augs}. However, these augmentations did not significantly impacted the model performance in any way. This is not that supprising since these augmentations did not bring much novelty into the data. Except the in-plane-rotations which change the overall magnetication of ferromagnets. 

Next we moved to augmentations that can combine different phases which results in non-physical configurations. The best performance on the skyrmion-spiral phase transition without augmentations was $50$ measured by our out-of-order metric. With a use of CutMixes on between skyrmion and spiral lattices, we were able to achieve $16$, which is $\approx 60\%$ improvement on this metric, while keeping the similar testing error on the clean configurations. However, CutMixes also hurt the prediction on the ferromagnet-skyrmion transitions, which was not problematic even for the models using solely non-augmented data. Both of these effects are visible in \ref{fig:ooo-cutmix}. The reason CutMixes work well on the skyrmion-spiral transition, can be explained through the lens of true, mixed, skyrmion-spiral configurations. We can see \ref{fig:trans_sk_sp}, that when the proportion of skyrmions and spirals in given configuration are similar, there are visible clusters of the same phase within the configuration. The CutMix creates such clustered configuration, that approximate the true physcal configuration well enought, that the model learns to interpret them better. By the same logic, CutMixes can hurt the performance on the ferromagnet-skyrmion phase transition \ref{fig:trans_fe_sk}, where the skyrmions in lattices continuously increase the spaces between each other, instead of creating clusters. That is also a probable reason, that MixUps slightly improve performance on this transition. As we can see figure \ref{fig:aug_fe}, the MixUp of ferromagnet and skyrmion lattice effectively makes the skyrmions smaller, making increasing the distance between them, similarly as in the true phase transition.

In the figure \ref{fig:model_comparison_aug} we qualitatively compare the predictions of skyrmion probability using multiple models on the phase transitions. Importantly, the predictions all for the phase that is not present in the given configuration were negligible for all models. We now focus on the models: None, CutMix, MixUp and Custom. \textbf{None} corresponds to the model trained without any data augmentations, \textbf{CutMix} and \textbf{MixUp} models were trained on CutMixes resp. MixUps between all $3$ phases, and \textbf{Custom} was trained using MixUps with ferromagnet and skyrmion samples, and CutMixes with skyrmion and spiral samples. As we can see, tha None model is not very sensitive to the changes in configurations during phase transitions, and tends to change its predictions abruptly. MixUp model also changes abruptly on the skyrmion-spiral transition showing no improvement. On the ferromagnet skyrmion transition however, MixUp improves the predictions, moving towards the curve corresponding to the change in topological charge. On the other hand CutMix model performs very badly on this trasition, even worse than the None model. CutMix helps a lot on the skyrmion-spiral transition where is helps the model more acuratelly estimate the amount of each phase on these configurations. The Custom model performed the best in this transition as it very closely follows the topological charge. It also performed the best out of our models on the ferromagnet-skyrmion transition, however here it does not follow the topological charge that closely.

\subsection{Dropout}

After seeing significant improvements in the model's performance on the phase transitions after the introduction of certain data augmentations, we are interested whether we can further improve with the use of dropout, spatial dropout and MC dropout. However, the larger values of both dropout ($> 0.3$), and spatial dropout ($> 0.2$) significantly disrupted the training, resulting in a poor perfomance on the testing dataset, without any noticeble improvements on the phase transitions. The largest value of these parameters, for which we achieved succesfull training were $0.1$ for both spatial dropout and dropout on the dense layers. For larger values the network tend to undertrain, even when increasing the models capacity and training time. Using the droout, we have an additional option to utilize MC dropout regularization. However averaging across $20$ up to $100$ predictions per sample with activated dropout did not significantly changed the resulting predictions.
